# Notes client — archive de travail

Ce répertoire conserve des notes historiques produites pendant les différentes phases de conception et de recette. Les fichiers `AUDIT-*`, `REPONSE-AUDIT-*` et autres notes datées ne constituent pas des rapports indépendants, des décisions produit ou une certification.

La source de vérité est `../documentation/README.md`. Les deux cahiers des charges restent distincts par intention : v1.7 est la base normative complète et v1.7.1 est son amendement court. Les nouvelles décisions, réserves et preuves doivent être ajoutées dans `../documentation/` avec une date, un commit et un périmètre, ou dans le suivi GitHub correspondant.

Aucun nouveau rapport généré automatiquement ne doit être ajouté ici. Les notes existantes peuvent être fusionnées ou supprimées lors d’une revue éditoriale dédiée, après vérification qu’elles ne contiennent pas une décision ou une preuve encore non reportée dans la documentation canonique.
